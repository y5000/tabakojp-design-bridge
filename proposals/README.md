# 美工主动提案 v1.3.0
美工Work自主选择页面、顺序、视觉布局交互和低风险体验提案，维护proposals/<自建唯一提案号>/vX.Y.Z/。本README/TEMPLATE由coordinator维护；其他提案版本由对应美工维护，不互改。
本轮提交一项确有合理frontend/backend职责的小范围改进，不涉及支付/订单/库存/权限；不能为凑模块造接口。暂不知道已有能力就写unknown，由coordinator核查，别假定缺失。
必需PROPOSAL.md、实际可运行原型源码/必要素材与README、FEATURE_REQUESTS及独立PROTOTYPE_TEST结果（实际运行/未测分开）；可引用自己已有原型Commit但不覆盖历史。模拟后端明确标注，不把原型当商城开发完成。
提案版本修订新目录，记录supersedes；coordinator从Git核实最终完整Commit及提交时间，feedback记录审核结果。没有用户对具体版本+Commit+授权范围批准前，公开提案submitted只表示等待审核，不是实施授权。
提案交付仍遵守公开敏感信息与素材许可/编码规则，用户不手动中转。
