# 龙吟主题开发协作说明 v1.0.1

适用主题：longyin（龙吟）。设计交付：TJP-HOME-20261014-master-001 v1.0.0，Commit a72e86b8889765b0362b2d7afa1f02045bdb32e2。

## 实现原则

- 前端以美工提交的 HTML、CSS、JavaScript 原型代码及组件交互结构为主要实现依据，视觉图片、截图和效果图作为辅助参考。保留可复用代码结构；接入 OpenCart 时使用真实数据并实现真实业务行为，不把演示数据或内存交互当作真实功能。
- 尚未实现、缺少已批准服务端能力或暂不安排开发的功能，先用明确的静态占位表达设计意图，并列入待完成清单。占位不得显示虚假的成功、价格、资格、库存或账户状态。
- 前端按美工代码接入真实且已核实的能力。任务已领取时，协调员可以通过公开说明和私有协作事件补充执行口径，但不因此改变原任务的授权范围。若实现需要超出原范围，前端应先报告协调员，通过正式范围修正后再继续。

## 服务端功能提议和排期

后端若发现需要新增服务端能力，应先向协调员说明功能目的、已有能力核查结果、所需接口或业务规则及影响。协调员负责转达用户，由用户决定何时安排开发。用户暂不安排的事项登记在待完成清单，并由协调员同步前端、后端和美工。未获批准前，后端不启动新增业务开发，前端不以模拟数据冒充真实功能。

## 角色说明

**美工：**前端会以你提交的 HTML、CSS、JavaScript 代码为主要实现依据，以图片和效果图为辅助。当前未实现或暂不排期的功能会先用静态占位表达，并记录为待完成。请在交付中标明真实行为与模拟行为，并将新增服务端功能建议提交协调员。

**前端：**以美工提交的代码为主、视觉图片为辅。根据已审查的能力契约接入真实功能；暂未实现或未排期的功能用不误导用户的静态占位，并记入待完成清单。遵守原任务授权、主题独立性及预览限制。发现范围不足时先报告协调员。

**后端：**发现需要新增服务端能力时先联系协调员，不自行启动开发。协调员转达用户，由用户决定开发时机。暂不安排的功能记入待完成清单，并由协调员同步前端、后端和美工。
