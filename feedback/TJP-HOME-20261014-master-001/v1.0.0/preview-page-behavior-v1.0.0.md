# 龙吟首页原型修订反馈：页面文案、轮播与手机底部导航

反馈状态：待美工提交修订版本  
适用范围：该首页代码预览的下一修订版本；这是设计交付反馈，不代表商城业务或后端授权。

## 页面中只保留最终会展示的内容

代码预览的实际页面上，不要显示仅用于解释原型、测试或交付状态，且不会出现在最终商城页面的文字。例如“首页交付原型 · 价格／优惠／数量皆为演示 说明”等说明条、测试提示或阶段备注。

如果需要解释模拟数据、运行方式、未实现功能或原型限制，请写在交付目录的 README、测试记录或功能说明中，不要放进用户可见页面。页面需要展示的正常商城文案仍按设计方案保留。

## 轮播必须真实切换

首页幻灯片需要由多个实际轮播项组成，并能通过自动播放、圆点或其他设计规定的控制切换到不同图片/内容。每个控制都要对应真实状态变化，不能只在一张已经拼好的静态图片上覆盖切换按钮或圆点。

如果当前只有一张素材，不要用装饰性按钮伪装可用轮播；请隐藏无效控制，或在交付说明中列出缺少素材并标记未完成。切换后的图片、指示状态与点击目标应彼此一致。

## 手机底部导航要有真实贴底效果

手机端底部导航应按最终设计表现贴合视口底部；如果设计意图是固定导航，页面滚动时导航应保持在屏幕底部，而不是仅出现在文档内容的末尾。导航入口应可操作并对应正确页面或明确的原型行为。

同时处理设备安全区和页面底部留白，确保导航不会遮挡最后一项内容；请在手机视口实际滚动检查贴底效果与内容可见性。不要只在静态截图中把导航画在页面底部。

## 修订交付

请在不覆盖 v1.0.0 历史文件的前提下提交新的交付版本，说明运行方法及实际检查结果。分别记录原型中已真实操作验证的轮播、导航行为，以及尚未测试的项目；不要将静态展示描述为交互已通过。

此反馈只要求设计预览呈现真实页面行为，不要求美工实现尚未批准的服务端功能。协调员审查修订后，再按既有流程安排后续工作。
