# v1.0.0 首页调整 · 草稿 r01

本轮以正式首页母版 v1.0.0 为起点，根据用户授权上传独立 `previews/longyin-home-v1-adjustment-20261017-r01/` 草稿，供在线视觉确认。不是正式设计交付，也不代表设计已批准或商城开发已获授权。母版及正式任务文件保持不变。

## 本轮内容

1. 固定底部导航；手机蓝色主体由母版约80px调整为40px，手机安全区另计。图标统一26×26px，图标与文字按40×40px对齐框排列，实际按钮44×44px。最终页面不显示虚线。
2. 商品图片使用1:1正方形；右侧详情与图片同高，标签在顶部、购买区域在底部。保留原商品名称、文字、价格、参考价和图片内容。
3. 页面不显示原型/演示/交付说明条、标签或内部技术说明。消费者可见的标题、卡片、优惠券、价格、搜索和导航均由真实网页元素实现。
4. 轮播的每一页是一张独立、完整的广告图片，图片内文字属于广告素材，网页不额外拆分为左文字右图片。支持圆点、PC箭头、键盘和触摸切换；整张广告可点击。没有自动播放。

## 文件和替换素材

- `index.html`、`styles.css`、`adjustments.css`、`app.js` 和 `assets/` 是相对路径的标准原型源码。
- `assets/ad-01.jpg` 复用既有中秋整图素材。`ad-02.svg`、`ad-03.svg` 是用于展示切换的可替换临时整图广告，不代表用户已批准新的活动或广告设计。
- 待用户提供正式广告图片后，替换对应素材路径即可，轮播不依赖广告内部的文字、按钮位置或图片内容。
- Logo、品牌标识、商品照片从用户原始母版按原素材区域提取为独立文件；页面不再通过整页母版截图或透明热区替代UI。
- 自包含HTML仅为离线预览备用包装，内嵌的data URI只包含正常图片素材；标准源码包继续使用相对路径图片。
