# 功能建议模板 v1.1.0（不是开发任务）
将本模板复制到自己交付版本目录的FEATURE_REQUESTS.md。每项独立编号，例如<设计任务号>-F01。

- 功能编号、任务版本及原型交付Commit：实际值
- 提议：新增/调整及目标
- 预期用户操作、状态变化和展示效果
- 需要的数据、字段与接口假设（未知明确标注）
- 原型当前实现：模拟/静态/真实接口/尚未实现；依据和限制
- 需确认业务规则、支付行为、数据权限及范围影响
- 前端交互要求与服务端需求，依赖与验收建议
- 已知现有能力线索（由协调员核实，不自行认定已部署）

美工不自行授予开发权限，不把待开发功能写成已实现。协调员在feedback逐项反馈能力检查、安排和用户确认状态。
