## 內容與使用方式

- `index.html` 是單文件 HTML，已內嵌母版圖片，不依賴外部圖片或網絡資源。
- 下载文件后用浏览器打开；页面按窗口宽度等比例显示，不拉伸、不裁切。
- 这版以截图作视觉画面，因此视觉像素来自原图；文字、按钮和购物交互不是独立 HTML 控件，也没有真实功能。
- GitHub 文件页用于查看源码/下载。仓库当前未启用 GitHub Pages，所以 GitHub 不会直接把此文件作为网站页面运行。
