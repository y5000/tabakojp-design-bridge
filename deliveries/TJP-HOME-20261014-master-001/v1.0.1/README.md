# 龍吟首頁 HTML 原型 r02

狀態：工作草稿，等待人類美工確認視覺；未正式交付、未獲採用、未授權商城開發。

本版把首頁的頁首、搜尋框、法規提示、優惠券、品牌卡、服務承諾、推薦商品卡、價格和底部導覽改為真實 HTML/CSS 元素。商品名稱、價格、優惠文案等可獨立編輯。橫幅、品牌 Logo 和商品照片作為獨立圖片素材，使用相對路徑載入。

## 預覽方式

在本資料夾執行：

```sh
python3 -m http.server 8000
```

然後在同一台裝置的瀏覽器打開 `http://localhost:8000/`。需保留 `assets/` 目錄與 `index.html` 的相對位置。

## 原型交互

- 搜尋欄提交後顯示演示搜尋提示並定位推薦商品。
- 優惠券按鈕可切換為已領取。
- 加入購物車按鈕會增加演示購物車數量；購物車按鈕開啟演示抽屜。
- 收藏按鈕可切換收藏狀態。
- 品牌卡和底部導覽可以操作並定位頁面。

搜尋結果、優惠券領取、購物車資料、收藏狀態均為前端演示，尚未連接 OpenCart API；演示操作不會建立真實訂單或改變商城資料。頁面不含真實支付、庫存扣減或帳戶操作。
