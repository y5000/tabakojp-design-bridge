# 正式接入候选说明（不是实施授权）

当前只交付原型。所有演示数据应被正式服务端数据替换，禁止把截图值硬编码为业务规则。协作流程：coordinator核查→明确文件/接口scope→用户批准→正式前后端任务→部署证据→用户许可美工复核。

| 区域 | 当前原型 | 正式接入要求 |
|---|---|---|
| 搜索 | 本地dialog显示关键字，不请求网站 | 复用现有搜索route、搜索参数与结果，不造新搜索引擎 |
| 品牌 | 本地品牌说明 | 从真实manufacturer_id生成URL，不凭名称猜ID |
| 主广告 | 母版图+品牌滚动热点 | 配置真实banner图/alt/link，轮播复用现有能力 |
| 公告/新会员 | 演示说明，不开户 | 复用公告、注册入口；500点需核实已批准活动条件 |
| 优惠券 | Set去重，本地「已领取」 | 登录/领取资格、有效期、金额、状态由服务端校验；接口unknown，不能假定缺失 |
| 服务三项 | 母版文案 | 核实现有支付方式、物流/订单可查范围，不把口号当技术证据 |
| 推荐商品 | 母版1条静态文字图片 | 复用真实product_id、名称/图片、币种、单位、售价、参考价、标签、销售计数、详情URL |
| 满10条减500 | 演示文本 | 服务端优惠资格与计算，未经批准不实现/修改价格规则 |
| 收藏 | 内存bool | 接入已授权用户收藏能力，登录/状态由真实系统决定 |
| 加购 | 内存计数，母版初始3 | 保留现有数量/规格选择/加购/反馈；真实API及后台校验，不由UI算库存/价格 |
| 购物车/分类/我的 | 本地演示入口 | 沿用既有真实入口，不覆盖其功能 |

前端建议：增量替换首页模板的视觉结构，CSS迁移到tjp-home命名空间，保留header/cart/search/导航功能hooks，拆分数据渲染组件，设置独立主题或首页feature flag。不要直接复制演示app.js作为生产交互。界面不应从母版截图读取价格。
后端建议：只核实/复用已批准能力并提供去敏接口摘要。这个首页任务不授权任何新后端规则；确需新增时提交FEATURE_REQUESTS由协调员拆分并取得批准。
回退：保留旧首页模板与CSS版本；仅关闭首页开关恢复旧主题，不删除历史交付。正式源码、服务器路径、token、账号等不得公开写入本仓库。

验收：与本母版对照模块/配色/内容顺序；桌面1363×936、手机393×852和360×800无水平溢出、按钮可操作、底栏不挡内容；真实品牌/详情/搜索正确；真实领券、收藏和加购仅在专用测试账号/模拟资料及明确许可下测试。正式支付/下单/库存/账户权限排除。必须记录部署Commit、设计交付Commit、检查时间与pass/rework/not_tested。
