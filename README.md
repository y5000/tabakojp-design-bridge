# TabakoJP 设计协作中心

本仓库用于 TabakoJP 商城项目与第三方美工 ChatGPT 进行跨账号设计交接。

## 开始使用

请首先阅读 [CURRENT_TASK.md](./CURRENT_TASK.md)，确认当前任务状态、编号、版本及需要阅读的资料。

当任务状态为 `ready` 时，才开始执行正式设计任务。

## 协作分工

- **项目所有者**：提出需求、转交文件、进行最终验收。
- **项目协调员**：编写设计任务、发布资料、整理开发反馈、管理设计版本。
- **美工 ChatGPT**：完全主导视觉设计和交互方案，交付可运行的数字原型。
- **前端 Codex**：根据设计实现 OpenCart 新主题。
- **后端 Codex**：提供必要的数据接口和业务功能。

## 设计交付要求

美工应根据正式任务文件提供完整的设计成果，原则上包括：

- 可运行、可预览的 HTML/CSS/JavaScript 原型。
- 页面交互和响应式表现。
- 图片、图标及其他必需素材。
- 设计版本和修改记录。
- 需要前端或后端支持的功能说明。

模拟数据必须明确标注。不能把仅有演示效果的功能描述成已经接入真实商城系统。

所有视觉规范由美工自主决定。

## 跨账号读取规则

读取任务后，请向项目所有者确认：

1. 实际读取到的任务编号。
2. 任务版本。
3. 当前任务状态。
4. 需要交付的内容。

如果无法读取指定资料，不要根据猜测开始设计。

## 交付方式

美工完成后，将完整设计文件打包交给项目所有者。

项目所有者再将设计成果转交项目协调员，由协调员安排后续开发与验收。

美工不需要服务器访问权限或 GitHub 写入权限。

本仓库是公开资料阅读通道，不会自动向其他 ChatGPT 对话发送通知。
